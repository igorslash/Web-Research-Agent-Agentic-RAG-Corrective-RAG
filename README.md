# Autonomous-Web-Research-Agent-Agentic-RAG-Corrective-RAG
Разработал мультишагового исследовательского RAG-агента на базе LangGraph (узлы planner, search, evaluate, writer и маршрутизация через Conditional Edges), автоматизирующего подготовку аналитических отчетов по сложным multi-hop запросам с проверяемыми inline-ссылками.
